# Analytics & Reports Skill

## Capabilities
- Generate dashboard summaries with key metrics
- Pipeline forecasting with probability-weighted projections
- Lead score distribution analysis
- Campaign performance reports with benchmark comparisons
- Agent activity and token usage reports
- Trend detection (WoW, MoM)

## When to Use
- User says "show me", "how's the pipeline", "report on", "summarize"
- Cron: daily brief (morning), weekly summary (Monday), monthly review (1st)

## Report Types
- **Daily Brief**: New contacts, tasks due, deal movement
- **Weekly Summary**: Pipeline health, campaign results, top performers
- **Monthly Review**: Full funnel, revenue forecast, agent ROI
