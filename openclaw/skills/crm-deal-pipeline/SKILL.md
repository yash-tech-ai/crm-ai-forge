# Deal Pipeline Skill

## Capabilities
- Create and update deals across pipeline stages
- Generate call prep briefs with contact history and talking points
- Detect stale deals (no activity > 14 days)
- Forecast pipeline revenue using probability-weighted values
- Recommend next steps based on deal stage and activity history

## When to Use
- User says "create a deal", "move deal to", "call prep for", "pipeline summary"
- Event: deal created, stage changed, task overdue
- Cron: daily stale deal detection
