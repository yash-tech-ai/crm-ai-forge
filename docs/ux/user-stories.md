# User Experience Stories

> These stories illustrate how real users interact with CRM AI Forge throughout their workday. The key insight: **users never "use a CRM" — they talk to their AI team.**

## 4. Key UX Principles

### What Users Never Have To Do

| Traditional CRM | CRM AI Forge |
|----------------|-------------|
| Log in to a dashboard to check status | Get proactive updates on the channel you're already using |
| Navigate to Contacts > Search > Click > Edit | "Update Priya's title to CTO" |
| Build a segment manually with filters | "Show me insurance leads from webinars who haven't converted" |
| Configure automation rules step by step | "Set up a nurture sequence for new webinar attendees" |
| Switch between CRM and email to write follow-ups | "Draft a follow-up based on today's call" |
| Export data, open spreadsheet, make charts | "How's our pipeline compared to last month?" |
| Remember to check stale deals | Agent alerts you proactively every morning |

### The Dashboard Still Exists — It's Just Not Primary

The Next.js dashboard serves as:
- **Visual pipeline** — Kanban drag-and-drop for those who prefer visual management
- **Campaign builder** — Template editor with preview for marketing team
- **Bulk operations** — Import contacts, manage segments, configure settings
- **Agent oversight** — View agent action logs, configure permissions
- **Team management** — User roles, permissions, team structure

**The rule:** Anything you can do on the dashboard, you can also do via conversation. The dashboard is a companion, not a requirement.
